
# Mercado Campesino Digital de Yopal

## Descripción
Plataforma web para conectar productores campesinos con clientes, permitiendo publicar ofertas semanales y reservar productos para recogerlos en el punto de venta.

## Objetivo
Facilitar la comercialización de productos campesinos de Yopal mediante un sistema sencillo, accesible desde celulares y adaptado a la conectividad intermitente de las veredas.

## Tecnologías propuestas
- Frontend: HTML, CSS y JavaScript.
- Backend: Java con Spring Boot.
- Base de datos: PostgreSQL o MySQL.
- Control de versiones: Git y GitHub.

## Funcionalidades principales
- Registro y gestión de usuarios según su rol.
- Publicación y consulta de ofertas semanales.
- Reservas con validación de disponibilidad.
- Cierre de reservas los viernes a las 6:00 p. m.
- Consulta y exportación de reportes autorizados.

## Estructura del proyecto
- docs/: documentación y diagramas.
- frontend/: interfaz de usuario.
- backend/: lógica de negocio y API REST.
- database/: modelo de datos y scripts SQL.
- tests/: pruebas del sistema.

## Estrategia de ramas
- main: versión estable del proyecto.
- develop: integración del desarrollo.
- feature/nombre-funcionalidad: desarrollo de cada funcionalidad.

## Estado del proyecto
En fase de diseño e implementación académica.
